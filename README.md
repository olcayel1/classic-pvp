# Classic PvP 75.0

Mobil tarayıcıda çalışan çok oyunculu oyun.

## Çalıştırma

Node.js 20 veya üstü kurulu bir bilgisayarda proje klasöründe `npm install` ardından `npm start` çalıştırın. Tarayıcıdan `http://localhost:3000` adresini açın. Farklı telefondan denemek için sunucunun herkese açık bir web hizmetinde çalışması gerekir.

## Render

Arşivi GitHub deposuna kökünde `server.js`, `package.json`, `public/index.html` ve `mods/` olacak şekilde ekleyin. Render Web Service ayarında Build Command `npm install`, Start Command `npm start` kullanın. Dağıtım bitince Render adresini telefonda açın.

`/healthz` adresi sunucu sürümünü gösterir.
